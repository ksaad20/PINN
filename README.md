# PINN
This repository contains Physics Informed Neural Network Research.

Format 

Dataset: Publicly available high quality data only.

Architecture: Physics Equation based data enabled models.

1. LSTM Hybrid 
2. Gated Recurrent Unit 
3. Transformer Encoder 
4. Multi Layer Perception
5. Multi Fidelity 
6. Split Network 
7. ResNet

Evaluation Metrics:

1. L-Squared Error
2. Mean Squared Error
3. Mean Absolute Error
4. PDE Residual 
5. Relative Parameter Error
6. Relative Stability Variance
7. Convergence Rate
8. Uncertainty Quantification
